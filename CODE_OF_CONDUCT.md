# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Participation must be harassment-free.

**Expected:** welcoming language, respect for differing viewpoints, constructive criticism.

**Unacceptable:** sexualized content, trolling, insults, harassment, doxxing.

**Scope:** all project spaces and any public representation of the project.

**Reporting:** email **agnostic-ai@chemaclass.es**. Reports are confidential; maintainers respond appropriate to the circumstances.
