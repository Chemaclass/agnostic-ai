# Code of Conduct

## Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Standards

Helpful behavior:

- Welcoming, inclusive language
- Respect for differing viewpoints
- Accepting constructive criticism
- Focus on what is best for the community

Unacceptable behavior:

- Sexualized language or imagery
- Trolling, insults, personal or political attacks
- Public or private harassment
- Publishing private information without permission
- Other conduct inappropriate in a professional setting

## Scope

Applies in all project spaces and when representing the project in public.

## Enforcement

Report violations to **conduct@chemaclass.dev**. All reports are reviewed and met with a response appropriate to the circumstances. Maintainers keep the reporter's identity confidential.
