### General

- On Linux, the companion's circle is see-through instead of sitting on a light square, and its list opens beside the circle. `agnostic-ai companion install` names every missing build package at once, with one install line for `apt`, `dnf` or `pacman` (#3222).
- On Linux, a click on an ended terminal chat resumes it in a new `x-terminal-emulator` window, and Claude Code cloud sessions list with the sign-in from `~/.claude/.credentials.json` (#3222).
