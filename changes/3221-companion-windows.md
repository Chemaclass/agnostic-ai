### General

- On Windows, a click in the companion list opens editor chats, Codex threads and cloud sessions in their apps, and resumes an ended terminal chat in a new PowerShell window. A terminal chat written in the last day is not resumed, because Windows processes cannot be checked; the list offers its command instead (#3221).
- The companion list says when Codex, Cursor or ChatGPT chats are missing because the `sqlite3` command is not installed (#3221).
