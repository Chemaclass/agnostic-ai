### General

- A model an agent states in a mailbox message no longer replaces the model label you entered on a review request, so the same-model warning follows your labels.
- Path claims made by an agent, with `agnostic-ai mailbox claim` or by accepting a handoff, are recorded as made by the agent.
- On Linux, the companion types copied text into a live chat in a Konsole tab, like the other tab apps.
- On Linux, text over 128 KB sent to a kitty tab goes in parts instead of failing. WezTerm gets any text as one paste, so two sends to one tab never mix.
- On Linux and Windows, opening an editor chat no longer says its folder could not be opened; it says this system cannot open the folder first.
- The companion's update check says "this computer" instead of "this Mac" when no newer version exists.
