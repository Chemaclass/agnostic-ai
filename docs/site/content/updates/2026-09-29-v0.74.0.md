## What changed

- `requires: "0.74.0"` pins one release, and a binary outside it stops with AAI-005 naming its install command, such as `pnpm install` (#1399, #1411).
- Environment specs write `.codex/environments/environment.toml` with worktree setup, cleanup, and one action button per dev command (#1393, #1411).
- `explain --inputs` lists every file a hook should watch, and `sync.output-manifest` commits the list of generated paths so CI names a leftover with no `.sync-state` (#1411).

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.74.0).
