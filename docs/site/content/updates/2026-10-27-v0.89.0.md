## Upgrading from v0.88.0 {#actions}

Stop running `agnostic-ai watch` processes before changing the installation or project config.

**Update web API clients before upgrading.** Edit and built-in preview requests must send `scope` as `team` or `local`. `/api/health` no longer returns `revision`. See the [API reference](@/docs/cli-reference/inspect.md#api) for the request and response fields.

**Plan before downgrading global sync.** Global sync writes ownership state version 9. Older releases cannot read that state. Keep a copy of your global configuration and state if you need to return to an older release; do not delete the state to bypass the check.

Install through your existing package manager. For a global npm installation:

```bash
npm install -g agnostic-ai@0.89.0
```

After installing, `agnostic-ai upgrade --requires` updates `requires` and the editor schema URL, then syncs. It replaces minimum or range requirements and local overrides too. To preserve a deliberate minimum or range, keep that requirement and update the schema URL to `v0.89.0` yourself. See [upgrade options](@/docs/cli-reference/upgrades.md#upgrade).

Run `agnostic-ai sync`, review the generated diff, and run `agnostic-ai sync --check` before restarting watch. The `caveman` built-in now ships only `SKILL.md`. Sync removes generated extras and keeps edited ones; review the kept files, then delete them, run `agnostic-ai doctor --fix`, or list them in `sync.unmanaged`.

## What agnostic-ai changed

### Review startup context

In `agnostic-ai view`, **Context size** ranks startup, file-scoped, and on-demand text for a selected target. It finds repeated startup passages and links to their sources. Copy a review prompt to ask a coding agent to compare them before changing a spec. The report counts words and bytes, not model tokens. You can also run:

```bash
agnostic-ai explain --context --target claude
```

See [context contributions](@/docs/cli-reference/inspect.md#rank-context-contributions) for what the report includes.

### Edit settings for your team or yourself

The browser can edit model, reasoning effort, and global session retention. Select **Team** or **Just me**, see the value each configured tool receives, and preview project model or effort changes before applying them. Undo restores the previous files while the server session remains open. Search spans configuration sections, and findings can be rechecked or opened in an editor. See [editing scope](@/docs/cli-reference/inspect.md#edit-scope).

### Find changes and compare tools faster

`sync -v` highlights changed targets and new coverage notes; `sync -vv` lists every target and repeated note. Parallel sync preserves shared Copilot commands. Global sync respects target filters, protects changed symlink targets, and saves removed files when `--backup` is set. `compare` now reads sync state once, reducing a 500-spec comparison from several minutes to about a second in the project's measurements.

The `terra` alias resolves to `gpt-6.1-terra`. See the [full release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.89.0) for the remaining fixes and changes.

## What changed in the targets

- **Qwen Code supports file-matched rules.** Its [rules documentation](https://qwenlm.github.io/qwen-code-docs/en/users/features/rules/), checked October 27, describes loading a rule after a matching file is read or edited. agnostic-ai now writes portable rules with `globs` to `.qwen/rules/<name>.md` with native `paths:`, and imports those paths back. This maps an existing Qwen feature; see the [Qwen guide](@/docs/targets/qwen.md#native-mappings) for scope and trust limits.
