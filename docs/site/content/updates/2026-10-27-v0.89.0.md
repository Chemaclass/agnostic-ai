## Upgrading from v0.88.0 {#actions}

Stop any running `agnostic-ai watch` process before you update the install or the project config.

**Update web API clients before you upgrade.** Edit and built-in preview requests must send `scope` as `team` or `local`. `/api/health` no longer returns `revision`. See the [API reference](@/docs/cli-reference/inspect.md#api) for request and response fields.

**Plan before you downgrade global sync.** Global sync writes ownership state version 9, which older releases cannot read. If you may need an older release, keep a copy of your global config and state. Do not delete the state to get past the check.

Install through your package manager. For a global npm install:

```bash
npm install -g agnostic-ai@0.89.0
```

After you install, `agnostic-ai upgrade --requires` sets `requires` and the editor schema URL, then syncs. It also replaces minimum or range requirements and local overrides. To keep a minimum or range, leave it as is and set the schema URL to `v0.89.0` yourself. See [upgrade options](@/docs/cli-reference/upgrades.md#upgrade).

Run `agnostic-ai sync`, review the diff, and run `agnostic-ai sync --check` before you restart watch. The `caveman` built-in now ships only `SKILL.md`. Sync removes its generated extras and keeps edited ones. Review the kept files, then delete them, run `agnostic-ai doctor --fix`, or list them in `sync.unmanaged`.

## What agnostic-ai changed

### Review startup context

In `agnostic-ai view`, **Context size** ranks startup, file-scoped and on-demand text for a target. It finds repeated startup passages and links to their sources. Copy the review prompt to have a coding agent compare them before you change a spec. The report counts words and bytes, not model tokens. From the CLI:

```bash
agnostic-ai explain --context --target claude
```

See [context contributions](@/docs/cli-reference/inspect.md#rank-context-contributions) for what the report includes.

### Edit settings for your team or yourself

The browser edits model, reasoning effort and global session retention. Pick **Team** or **Just me**, see the value each tool gets, and preview project model or effort changes before you apply them. Undo restores the previous files while the server session is open. Search covers config sections, and you can recheck a finding or open it in an editor. See [editing scope](@/docs/cli-reference/inspect.md#edit-scope).

### Find changes and compare tools faster

`sync -v` highlights changed targets and new coverage notes. `sync -vv` lists every target and repeated note. Parallel sync keeps shared Copilot commands. Global sync respects target filters, protects changed symlink targets, and saves removed files with `--backup`. `compare` on 500 specs drops from several minutes to about a second in the project's measurements.

The `terra` alias resolves to `gpt-6.1-terra`. See the [full release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.89.0) for the remaining fixes.

## What changed in the targets

- **Qwen Code supports file-matched rules.** Its [rules docs](https://qwenlm.github.io/qwen-code-docs/en/users/features/rules/) (checked October 27) say a rule loads after a matching file is read or edited. agnostic-ai now writes portable rules with `globs` to `.qwen/rules/<name>.md` with native `paths:`, and imports those paths back. See the [Qwen guide](@/docs/targets/qwen.md#native-mappings) for scope and trust limits.
