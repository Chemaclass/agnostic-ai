## What to do {#actions}

1. If your automation relied on `init` enabling every target, add `--all` to that command (one flag per command).

Nothing else needs action.

## What changed

- `import all` and its dry run skip entry files that point outside the project (#1138, #1139, #1141, #1142).
- Cursor `sync` warns when emitted `BUGBOT.md` files exceed Bugbot's file or review budget (#1125, #1126).
- `init` and `import all` recognize a root `CLAUDE.md` or `GEMINI.md` as an existing setup (#1137).

Everything else is in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.68.0).

## Upstream CLI and model news

- **Cursor Bugbot** (docs checked 2026-09-25): team, repository, and project rules share a 100,000-character review budget, so a file below the limit can still be omitted. agnostic-ai warns for emitted files; use Cursor's verbose review to see the full set. State: supported. [Bugbot rules](https://cursor.com/docs/bugbot#rule-limits)
