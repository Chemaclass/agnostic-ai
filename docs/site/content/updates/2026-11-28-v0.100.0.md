## Highlights {#highlights}

- **Breaking:** the Companion is now Agnostic Companion. `make companion` builds `agnostic-companion`, and macOS downloads use that name. [Install and start](@/docs/cli-reference/companion.md#install).
- `builtins: [autosync]` and `install-hook` keep generated tool files current after a clone, pull, rebase or branch switch. [Sync on session start](@/docs/autosync.md).
- Cloud agents get their setup from Git, with `doctor environment` to check it and install steps for Claude Code and Copilot. [Cloud environment checklist](@/docs/cli-reference/doctor.md#doctor-environment).
- Rename a chat by renaming its Ghostty, WezTerm or kitty tab, pin chats, and drag one chat onto another to start a handoff. [Companion list](@/docs/cli-reference/companion-list.md#the-list).
- Web Conversations groups chats by attention, filters by place and tool, and offers the Companion's row actions and pins.

## Upgrading from v0.99.0 {#actions}

- **Scripts that build or download the Companion:** use `agnostic-companion` from `make companion`, and `agnostic-companion_darwin_<arch>` for the macOS `.dmg` and `.tar.gz`. The old disk image name stays available through v1.0.0 and for at least 30 days after this release, whichever is later. See [Install and start](@/docs/cli-reference/companion.md#install).

Installed apps need no action: `agnostic-ai companion` keeps your settings, and disk-image updates keep the app's path. Then follow the [upgrade page](@/docs/cli-reference/upgrades.md#upgrade).

## What changed

### Tool files stay current on their own

Add `builtins: [autosync]` to run `sync --keep-edits` when a session starts in any tool that has a session-start hook. A fresh clone, pull, rebase or new worktree then starts with current files. The hook never fails the session and names only the files it kept. `install-hook --post-checkout` now also covers rebases. In a project that uses lefthook, husky or pre-commit, it prints the lines to add to that tool's config instead of writing a hook. [Sync on session start](@/docs/autosync.md), [Git hooks](@/docs/git-hooks.md#hook-managers).

### Cloud agents start with their setup

Cloud agents only read committed files. `gitignore.commit: [cloud]` keeps the instructions and setup files they need in Git. `doctor environment` lists those files, their Git status, the `.gitignore` lines to change, and the variable, secret and domain names your environment spec declares.

- Claude Code: `sync` turns the environment's `install` commands into a cloud session hook.
- GitHub Copilot: `x-copilot.setup-steps` generates the setup workflow, and `cloud-handoff` can send a task to the Copilot coding agent (preview).
- Cursor: declared domains become `egressAllowlist`.

[Cloud environment checklist](@/docs/cli-reference/doctor.md#doctor-environment), [Cloud handoff](@/docs/cloud-handoff.md).

### Work with chats in fewer steps

In Agnostic Companion, rename a single-pane Ghostty, WezTerm or kitty tab and the chat takes the new name. The [tab rename guide](@/docs/cli-reference/companion-tab-rename.md) lists the tested versions. Pin a chat to keep it at the top; web Conversations shares the same pins. Drag one chat onto another to open the handoff form with both chosen. Waiting mailbox threads say what delivery needs and offer **Copy message**. Settings use the same sections as the web, with an Updates panel and a keyboard shortcut list.

### Web Conversations sorts by what needs you

Chats that need you come first, then working, active and archived chats. Filter by All, Local or Cloud and by tool. Each row has the Companion's actions: copy details, rename, mark read or complete, hide or delete archived chats.

See the [release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.100.0) for the remaining fixes.
