## What changed

- A project that runs `sync` with no `.sync-state` now sees each leftover output named, with how to remove it, instead of a silent pass (#1334, #1354, #1362).
- Environment specs take `setup` for new worktrees, written to `.cursor/worktrees.json`, and `dev-commands` for preview servers, written to `.claude/launch.json` (#1339, #1340).
- `sync --untrack` untracks generated files Git ignores, and `install-hook --post-checkout` runs a sync after each checkout (#1330).

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.73.0).

## Upstream CLI and model news

- **Factory Droid** (docs checked 2026-09-28): `commandAllowlist`, `commandDenylist`, and `commandBlocklist` are deprecated in favor of `permissionRules`, and are still read. Synced permissions keep using the lists; `x-factory.permissionRules` reaches the new schema. State: target extension. [LLM safety and agent controls](https://docs.factory.ai/enterprise/llm-safety-and-agent-controls)
- **GitHub Copilot CLI** (docs checked 2026-09-28): a `subagentStart` hook's `matcher` is a regex on the agent name, not a tool name. Hook notes now say what each camelCase event's matcher tests. State: supported. [Hooks reference](https://docs.github.com/en/copilot/reference/hooks-reference)
