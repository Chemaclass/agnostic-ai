## Upgrading from v0.72.0 {#actions}

Stop `sync --watch`. If adopting new config keys, set `requires: ">=0.73.0"` and update a release-pinned schema URL to the `v0.73.0` tag before a postinstall can sync. This release accepts minimum requirements only; pin the installed package or binary for reproducibility. Choose your existing channel:

**Standalone macOS/Linux:** `agnostic-ai upgrade --version v0.73.0`.

**Project npm dependency:** `npm install --save-dev --save-exact agnostic-ai@0.73.0`.

Use the local runner for project dependencies and check `agnostic-ai --version`. Choose committed kinds or a checkout hook, then regenerate and review:

```bash
agnostic-ai sync
agnostic-ai sync --check
```

Resolve newly reported leftover files, or put deliberately hand-maintained paths under `sync.unmanaged`. Commit the config, lockfile and selected outputs together. Copilot `subagentStart` matchers must name agents rather than tools. [Installation](@/docs/installation.md).

## What agnostic-ai changed

### Make fresh checkouts usable

Choose generated kinds that must be available before sync:

```yaml
gitignore:
  enabled: true
  commit: [instructions, hooks]
```

This keeps instructions and hook outputs visible to Git across configured targets, while other kinds remain ignored. `sync --untrack` removes tracked-and-ignored generated paths from the index without deleting working copies; review that opt-in change before committing.

For ignored outputs, `agnostic-ai install-hook --post-checkout` regenerates them after a branch or worktree checkout. Add `--shared` for a repository `.githooks/` setup. The installed hook runs plain sync and can overwrite hand edits. A custom `--keep-edits` hook protects ledger-recorded edits, but v0.73 has no fresh-worktree fallback, so save edits before its first sync. [Git hooks](@/docs/git-hooks.md).

### Share worktree setup and preview servers

An environment can serve Cursor setup and Claude preview servers:

```yaml
name: dev
targets: [cursor, claude]
setup: pnpm install --frozen-lockfile
dev-commands:
  - name: Docs
    command: [pnpm, dev]
    cwd: apps/docs
    port: 3000
```

Cursor writes setup to `.cursor/worktrees.json`; `setup-windows` can override it. Claude writes the server to `.claude/launch.json`, preserving cwd and port. **Claude worktree setup still needs a hook in this release.** Both files each tool reads import back, and lint checks malformed dev commands. [Environment format](@/docs/spec-format/environments.md).

### Give Codex scoped review guidance

Review specs now write `Code Review Rules` sections to root or scoped Codex `AGENTS.md`. A review with `scope: backend` reaches `backend/AGENTS.md`, and also `backend/.cursor/BUGBOT.md` when targeting Cursor. Same-scope reviews concatenate and Codex imports them back. Other readers of the shared `AGENTS.md` also see that section. [Reviews](@/docs/spec-format/reviews.md).

### Find stale outputs without a ledger

Sync, check and doctor report leftover generated files in fresh checkouts without `.sync-state`. A successful sync can retain files it cannot safely remove, so resolve the reports rather than assuming cleanup succeeded. Import reruns avoid duplicate rules, references point to original sources, and init pins editor schemas to the installed release. The [comparison page](@/docs/compare.md) shows supported kinds and paths side by side. [Complete release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.73.0).

## What changed in the targets

- **Factory (docs checked September 28):** native `permissionRules` replaces deprecated command lists, which remain accepted. Portable permissions still write those lists; use `x-factory.permissionRules` for the newer schema. [Safety controls](https://docs.factory.ai/enterprise/llm-safety-and-agent-controls).
- **Copilot (reference checked September 28):** `subagentStart` matchers are full agent-name regexes. Use `code-review`, not `Bash`, for that agent; invalid patterns prevent firing and v0.73 reports them. [Matcher reference](https://docs.github.com/en/copilot/reference/hooks-reference#matcher-filtering).
- **Cursor Security Review (September 23):** Teams/Enterprise enable exploit-focused reviews per repository. This is separate from generated Bugbot instructions; no documented repository output is available for agnostic-ai. [Announcement](https://cursor.com/changelog/rollouts-and-security-reviewer).
- **Codex 0.158.0 (September 28):** OAuth client-secret connections use native CLI setup. v0.73 adds no portable secret field and does not claim syncing provisions the connection. [Release notes](https://github.com/openai/codex/releases/tag/rust-v0.158.0).
