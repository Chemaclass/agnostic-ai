## What to do {#actions}

1. If a project still syncs MCP servers to OpenHands, copy those MCP specs into `~/.agnostic-ai/mcps/` and run `agnostic-ai sync --global` (one copied file per server).

Nothing else needs action.

## What changed

- `sync --keep-edits` writes every output except the files edited since the last sync, and names each one it kept (#1271).
- A home settings spec sets `permissions.default-mode`, which lands as `permissions.defaultMode` in `~/.claude/settings.json` (#1245).
- `import` skips every `node_modules` directory, and validation rejects a spec scoped inside one (#1307, #1321).

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.72.0).
