## Highlights {#highlights}

- **Breaking:** Layer names have changed, and scripts that send chat text through the local server now need the companion or an unlocked browser tab. [Scopes](@/docs/scopes.md) and [conversations API](@/docs/cli-reference/conversations-api.md).
- Send questions, reviews and file handoffs between Claude Code and Codex sessions from the companion or from the agents themselves. [Mailbox](@/docs/mailbox.md).
- Approve or deny a Claude Code or Codex permission request from its companion row. [Approvals](@/docs/approvals.md).
- Companion updates verify the signer, show progress, and try to restore the earlier app if the new one fails to start. [Companion upgrades](@/docs/cli-reference/companion.md#upgrade-the-companion).
- Open or resume chats on Windows and Linux, and switch to the exact iTerm2, WezTerm, kitty, tmux or Konsole tab. [Companion list](@/docs/cli-reference/companion-list.md).

## Upgrading from v0.96.0 {#actions}

- Update scripts that read layer names. `project-user` is now `local`, `global` is `user`, and `global-local` is `user-local`. Replace `--global` with `--scope user`, the folder flag on `new rule` with `--dir`, and `doctor --scope` with `doctor --checks`. [Scopes](@/docs/scopes.md).
- Use the companion or a browser tab opened by `view` to send text, resume a terminal session, delete a chat, stop a session or shell, or rename a cloud chat. Update scripts that called those routes without proof. [Conversations API](@/docs/cli-reference/conversations-api.md).
- If you use Codex hook approvals, trust the updated hook in `/hooks` after `sync --scope user`. [Approvals](@/docs/approvals.md).
- Update the companion and CLI together. After upgrading directly through Homebrew or npm, run `agnostic-ai companion install`. On macOS, grant Accessibility again after the first install with the new signing or after switching install methods. [Installation](@/docs/installation.md) and [macOS permissions](@/docs/cli-reference/companion.md).

Follow the [upgrade guide](@/docs/cli-reference/upgrades.md#upgrade) to update the tool and your projects.

## What changed

### Work with another session

Open a row's mailbox to send a question, ask for a review, or hand off files. Agents can send through `agnostic-ai mailbox`, and the companion asks you before delivering their messages by default. A file claim shows on its owner's row, and both rows move to **Needs you** when their claims conflict. [Mailbox](@/docs/mailbox.md).

### Answer prompts and apply settings

![Approvals, mailbox and companion controls in the web settings tab](/assets/images/updates/v0.97.0-settings.png)

Use the companion's list menu or **Settings > Approvals and companion** in the user dashboard to select an approvals mode, turn on row approvals, and change companion options. **Apply to my tools** previews hook and MCP commands, including arguments, with detected credentials masked. A settings save protects edits made after it read the config. In Kiro, `review` adds the `approve-for-me` preset while keeping your permission rules. [Approvals](@/docs/approvals.md).

### Return to a chat

The companion can open chats on Windows and Linux. It brings supported terminals to the chat's tab and can jump to a teammate's tmux pane. If the server cannot tell whether a terminal session is still running, it shows the command to resume it by hand. [Companion list](@/docs/cli-reference/companion-list.md).

### Update the installed companion

The update menu shows each step. The macOS app checks the signer before launch and keeps the earlier app until the replacement stays up. Terminal installs can update the CLI and companion together. [Companion upgrades](@/docs/cli-reference/companion.md#upgrade-the-companion).

See the [release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.97.0) for the remaining fixes.
