## What to do {#actions}

1. **Kiro agents with `x-kiro.resources` and inheritance off:** add `file://AGENTS.md` to their resources, since `sync` no longer keeps steering copies for them (one line per agent).
2. **Gemini CLI hooks:** run `agnostic-ai lint` and replace each bare `$GEMINI_PROJECT_DIR` that LINT030 flags with `"${GEMINI_PROJECT_DIR}"` (one edit per flagged hook).

Nothing else needs action. Upgrade with `agnostic-ai upgrade --version v0.78.0`, or your usual [install channel](@/docs/installation.md), then run `agnostic-ai sync`.

## What changed

- [`agnostic-ai hook run`](@/docs/spec-format/hooks.md#hook-run) now runs hooks as Crush, Cursor, Copilot, Factory, Qoder, and Antigravity would, and counts assumed results only with `--include-assumed`.
- MCP `url` and `args` accept `${NAME}`, written in each tool's own form, and `$${NAME}` passes a literal `${NAME}` through.
- `--json` output from `sync --check`, `--plan`, and `--dry-run` lists warnings and notes, with `/` paths on every OS.

Every change is in the [v0.78.0 release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.78.0).

## Coding-tool and model news {#upstream-cli-and-model-news}

- **GitHub Copilot CLI** (2026-10-01): dynamic workflows run multi-agent processes from code in `.github/extensions/<name>/extension.mjs`, in public preview behind `--experimental`. agnostic-ai does not write them. State: watch. [GitHub changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app)
- **Claude Code 2.1.288** (docs checked 2026-10-03): `modelSettings.<model>.autoCompactWindow` sets when compaction starts for each model. Set it through `x-claude.modelSettings` in a settings spec. State: target extension. [Settings reference](https://code.claude.com/docs/en/settings-reference)
