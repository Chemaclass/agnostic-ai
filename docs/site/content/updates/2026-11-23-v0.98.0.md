## Highlights {#highlights}

- Start a task handoff from the companion by picking the receiving session. [Companion mailbox](@/docs/mailbox.md#hand-a-session-over).
- Send a task handoff with `mailbox send` to include your Git context and any saved handoff note. [Mailbox command](@/docs/cli-reference/mailbox.md#mailbox-send).
- See stopped Claude Code teammates' subagents leave **Working** when the team removes their owner. [Companion list](@/docs/cli-reference/companion-list.md#working-rows).

## Upgrading from v0.97.0 {#actions}

- If you send task handoffs, update the CLI and companion together. An older CLI skips threads that contain the new handoff format. [Mailbox API](@/docs/mailbox.md#mailbox-api).

Follow the [upgrade guide](@/docs/cli-reference/upgrades.md#upgrade).

## What changed

### Pass a task to another session

Right-click a local Claude Code or Codex session in a Git worktree and choose **Message another session**. The form starts on **Handoff** when you open a new thread. Pick the receiver and send. You can add a message or include claimed files.

![Companion handoff form with a Codex recipient and an optional note](/assets/images/updates/v0.98.0-task-handoff.png)

From an agent session, run `agnostic-ai mailbox send` in the source worktree. The server resolves the Git worktree, branch and commit. The recipient gets the message on its next prompt and waits for you to ask it to resume. When it resumes, it looks for the latest note in the source project, including a note saved after you sent the handoff. [Task handoffs](@/docs/mailbox.md#hand-a-session-over).

### Keep the Working list current

If Claude Code removes a teammate while its subagent's log still shows an open task, the companion clears the old subagent. An idle chat can then leave **Working**, and the list stops sending you to the removed teammate's row. [Working rows and subagents](@/docs/cli-reference/companion-list.md#working-rows).
