## What to do {#actions}

1. For rules that should use only `globs` or `paths`, remove `scope` and move the spec out of any folder that implies scope (one field and, for nested specs, one file move).
2. If a Claude Code environment spec has `setup`, delete an equivalent hand-written worktree bootstrap hook (one hook per project).
3. Run `agnostic-ai sync`.

Nothing else needs action.

## What changed

- Shared settings drop unchanged values your specs stop setting and keep your edits, MCP servers, and hooks.
- `hook run` checks guards for Claude Code, Codex, Gemini CLI, Trae, OpenHands, Goose, and Augment with each tool's payload.
- `protected` paths become guards for Claude Code, Codex, Gemini CLI, and Cursor from one settings block.

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.76.0).
