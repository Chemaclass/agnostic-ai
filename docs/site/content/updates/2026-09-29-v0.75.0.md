## What to do {#actions}

1. Upgrade from 0.74.0 or earlier, since those binaries carry the 18 Go vulnerabilities (`agnostic-ai upgrade`, or bump the npm pin).
2. If Claude Code is a target and `gitignore.enabled` is on, commit the `.worktreeinclude` the next sync writes (one file).
3. If you commit `CLAUDE.md` and another target writes `AGENTS.md`, commit the shorter `CLAUDE.md` the next sync writes (one file).

Nothing else needs action.

## What changed

- The root `CLAUDE.md` becomes `@AGENTS.md` plus your `::target claude` blocks when another target writes `AGENTS.md`, so Cursor stops loading the instructions twice (#1423).
- `gitignore.commit: [cursor:reviews, cursor:environments]` keeps only the Cursor files a cloud agent reads in Git, while local tools regenerate theirs (#1418).
- `sync --check --against` fails on a hand-written skill left in an ignored folder by a branch older than your move to `.agnostic-ai/`, and names the import that adopts it (#1420).

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.75.0).
