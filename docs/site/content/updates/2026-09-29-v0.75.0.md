## Upgrading from v0.74.0 {#actions}

Stop `sync --watch`. Manually update existing exact `requires` and release-pinned schema URLs to `0.75.0`/`v0.75.0`, regardless of install channel; keep a deliberate minimum/range that accepts it. Make config edits before a package install whose postinstall runs sync, then choose your existing channel:

**Standalone macOS/Linux:** `agnostic-ai upgrade --version v0.75.0`.

**Project npm dependency:** `npm install --save-dev --save-exact agnostic-ai@0.75.0`.

Use the local runner for project dependencies; [installation](@/docs/installation.md) covers other channels. Run `agnostic-ai --version`, then regenerate and check:

```bash
agnostic-ai sync
agnostic-ai lint
agnostic-ai sync --check
```

Commit the config, lockfile and tracked output changes. Claude users should review the new `.worktreeinclude` and the shorter `CLAUDE.md` when another target writes `AGENTS.md`.

## What agnostic-ai changed

### Verify patched release binaries

Binaries move from Go 1.26.0 to **Go 1.26.8**, including intervening security fixes for reachable standard-library vulnerabilities found by the project's scan. CI now gates on reachable vulnerabilities. [Go patch history](https://go.dev/doc/devel/release).

Each archive gains signed build provenance and an SPDX SBOM. Verify your downloaded archive with GitHub CLI:

```bash
gh attestation verify agnostic-ai_linux_amd64.tar.gz --repo Chemaclass/agnostic-ai
```

Use your OS/CPU filename. Installers now stop on unverifiable checksums; optional attestation checking requires GitHub CLI. The [verification guide](@/docs/verify-a-release.md) covers installer options, bundles and SBOMs.

### Share only the generated files a tool needs

Target-qualified commit entries let local tools regenerate their files while remote tools receive selected outputs:

```yaml
gitignore:
  enabled: true
  commit: [cursor:reviews, cursor:environments]
```

Unqualified kinds still select every target; lint warns about disabled targets. With Claude enabled, managed `.worktreeinclude` also carries ignored generated files and local specs into new worktrees. Keep it tracked when needed; `gitignore.worktree-include: false` opts out.

When another target writes root `AGENTS.md`, `CLAUDE.md` becomes its import plus Claude-only blocks. Cursor reads both files, so shared instructions load once.

### Put Cursor skills in each app workspace

A root skill can request additional workspace copies with frontmatter:

```yaml
workspaces: [apps/api, apps/web]
```

Sync keeps the root skill and copies its bundle into each app's `.cursor/skills/`. Source-layout-scoped skills retain their scope; a skill's `scope:` frontmatter is ineffective and now warns. [Cursor skills](@/docs/targets/cursor.md).

### Catch conflicts carried by older branches

`sync --check --against HEAD` now catches hand-written native config tracked inside managed ignored folders and names the import that can adopt it. Import also keeps separate environment files scoped to their original tools, while standard skills retain their `license`. [Complete release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.75.0).

## What changed in the targets

- **Amp (September 28):** `medium` defaults to Opus 5.5 instead of GPT-5.6 Sol; ChatGPT Only keeps GPT-5.6 Sol. Check the preset when comparing results or costs. This is native Amp model routing, with no new portable field in v0.75. [Announcement](https://ampcode.com/news/opus-5.5).
