## Highlights {#highlights}

- The [desktop companion](@/docs/cli-reference/inspect.md#companion) shows chats that need you and opens them where they live.
- [Conversations](@/docs/cli-reference/inspect.md#claude-code-cloud-sessions) can include Claude Code and Codex cloud sessions, and search covers your full local history.
- [Mistral Vibe sync](@/docs/targets/vibe.md#connections-settings-and-hooks) supports all seven native hook events from Vibe 3.1.1.

## What changed

### Find the chat that needs you

The companion puts a small conversation count over your other apps. Open its list with a click or a shortcut, search for a chat, and return to the terminal, editor or app where it lives. You can archive a conversation when you finish; a new message brings it back to your attention.

Installation builds the companion on your machine from the matching CLI source. It needs Go and the [platform dependencies](@/docs/cli-reference/inspect.md#companion). Rebuild it after upgrading the CLI. It has been run on macOS. It compiles on Windows but has not been run there. It has not been built or run on Linux.

The web interface also searches local conversations beyond the pages already loaded and labels new replies and archived chats. See the [conversation reference](@/docs/cli-reference/inspect.md#api) for states, search fields and local marks. Codex activity can be inferred from a running turn and its last write; a waiting label is not always an explicit request from the tool.

### Bring cloud chats into the list

Start `agnostic-ai serve --global --cloud-sessions` to add Claude Code and Codex cloud conversations. The companion enables this on its own server. Both use the sign-ins their tools already keep on your machine; Claude Code cloud listing currently requires macOS.

Each provider lists at most 100 cloud sessions. The server checks cloud lists at most once a minute and reads session details, not messages. Local chats remain available when a cloud service cannot be reached. See [cloud sessions](@/docs/cli-reference/inspect.md#claude-code-cloud-sessions) for access, limits and opening behavior.

### Get clearer upgrade results

Automatic upgrades started with v0.93.0 or later use the newly installed CLI to update `requires`. This lets fixes in the new release apply to that step. The result shows the new requirement, and a stopped upgrade says which release is installed. See the [upgrade reference](@/docs/cli-reference/upgrades.md#upgrade).

See the [release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.93.0) for the remaining fixes.

## What changed in the targets

- **Mistral Vibe 3.1.1** adds `pre_agent`, `notification`, `session_start` and `session_end` ([release](https://github.com/mistralai/mistral-vibe/releases/tag/v3.1.1)). Project and global sync now emit them alongside the existing three events. Strict mode is accepted only for `pre_tool`, `post_tool` and `pre_agent`, matching the released schema.
- **Windsurf / Devin Desktop** supports `disabledTools` and remote-server `oauthScopes` in its [MCP configuration](https://docs.devin.ai/cli/extensibility/mcp/configuration). Sync now keeps these fields. Its guide also describes [Devin Local's shared CLI discovery](https://docs.devin.ai/desktop/devin-local/customizations.md) separately from legacy Cascade.

Checked on November 10, 2026 against the linked vendor sources and generated output. Vibe's released parser and schema were exercised; native hook execution and Devin runtime behavior were not.
