## What to do {#actions}

1. On macOS 12 with Go 1.26.8 or a newer Go 1.26 patch installed, build with `GOTOOLCHAIN=local go install github.com/chemaclass/agnostic-ai/cmd/agnostic-ai@v0.77.0` (one install command).
2. For a rule with narrow `globs` that should load everywhere, add `alwaysApply: true` (one line per affected rule).
3. If sync reports an unknown config key, correct the named key in `agnostic-ai.yaml` (one entry per reported key).
4. Run `agnostic-ai sync`.

Nothing else needs action.

## What changed

- `agnostic-ai use <tool>` adds a target, imports existing config when supported, and syncs the project.
- Import, sync, watch, and validation use the same absolute source paths.
- Claude Code MCP import and sync preserve explicit boolean flags, including `alwaysLoad: false`.

Full details are in the [GitHub release notes](https://github.com/Chemaclass/agnostic-ai/releases/tag/v0.77.0).
