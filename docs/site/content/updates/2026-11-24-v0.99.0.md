## Highlights {#highlights}

- Copy the terminal command that resumes a Claude Code cloud session from the companion or web Conversations. [Cloud sessions](@/docs/cli-reference/companion.md#claude-code-cloud-sessions).
- The companion brings the right Codex terminal forward more often, and never offers a resume that competes with a running thread. [Open a chat](@/docs/cli-reference/companion-list.md#open-a-chat).
- The companion explains its chat menu, permission setup and mailbox actions, and its empty and disabled states say what they mean. [Companion list](@/docs/cli-reference/companion-list.md#the-list).
- Web Conversations says when cloud chats could not be loaded, and keeps the local resume command on shared chats. [Conversations](@/docs/cli-reference/conversations.md).

## What changed

### Pick up a cloud session in your terminal

Right-click a Claude Code cloud row in the companion and choose **Copy resume command**, or use the button of that name on its row in web Conversations. Paste the `claude --teleport` command into a terminal to continue there. The main click still opens the session on claude.ai. [Cloud handoff](@/docs/cloud-handoff.md).

### Reach the right Codex terminal

Clicking a Codex chat finds its tab after a delayed first prompt, and suggests the one terminal that can show a later chat. A thread the Codex background service still holds never gets a resume command, since a second copy would compete with it. Renaming or opening a chat leaves the old tab alone after its client exits. [Open a chat](@/docs/cli-reference/companion-list.md#open-a-chat).

### Read the companion at a glance

- The chat menu and permission setup explain each choice. Mailbox threads show one main action, with the rest under **More**.
- A **Send** button that cannot send yet looks disabled. Closing **Also give claimed files** clears its paths, so a handoff never keeps paths it will not send.
- With **Local** or **Cloud** chosen and nothing there, the list names that place instead of saying there are no conversations.
