# Documentation

Start with the guide for your task. Reference pages are for lookup; you do not need to read them in order.

| Your goal | Start here |
|---|---|
| Use agnostic-ai in a project | [Getting started](https://chemaclass.github.io/agnostic-ai/docs/getting-started/) |
| Install or upgrade the CLI | [Installation](https://chemaclass.github.io/agnostic-ai/docs/installation/) |
| Adopt it without losing existing instructions | [Migration](https://chemaclass.github.io/agnostic-ai/docs/migration/) |
| Share service or monorepo instructions across tools | [Directory-specific instructions](https://chemaclass.github.io/agnostic-ai/docs/scoped-context/) |
| Find a command, field, or output path | [User documentation](https://chemaclass.github.io/agnostic-ai/docs/) |
| Fix a setup or sync problem | [Troubleshooting](https://chemaclass.github.io/agnostic-ai/docs/troubleshooting/) |
| Track upstream target changes and proposed support | [AI tooling updates](https://chemaclass.github.io/agnostic-ai/updates/) |
| Build and contribute to the project | [Contributor setup](../CONTRIBUTING.md) |
| Understand or extend the implementation | [Contributor documentation](internal/README.md) |

Try the [browser playground](https://chemaclass.github.io/agnostic-ai/playground/) without installing anything, or use the [examples](examples/README.md) in a local project.
