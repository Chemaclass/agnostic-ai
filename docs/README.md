# Documentation

Start with the guide for your task. Reference pages are for lookup; you do not need to read them in order.

| Your goal | Start here |
|---|---|
| Let a coding agent install and configure agnostic-ai | [Agent setup](https://agnostic-ai.org/docs/agent-setup/) |
| Use agnostic-ai in a project | [Getting started](https://agnostic-ai.org/docs/getting-started/) |
| Install or upgrade the CLI | [Installation](https://agnostic-ai.org/docs/installation/) |
| Adopt it without losing existing instructions | [Migration](https://agnostic-ai.org/docs/migration/) |
| Share service or monorepo instructions across tools | [Directory-specific instructions](https://agnostic-ai.org/docs/scoped-context/) |
| Find a command, field, or output path | [User documentation](https://agnostic-ai.org/docs/) |
| Fix a setup or sync problem | [Troubleshooting](https://agnostic-ai.org/docs/troubleshooting/) |
| Track upstream target changes and proposed support | [AI tooling updates](https://agnostic-ai.org/updates/) |
| Build and contribute to the project | [Contributor setup](../CONTRIBUTING.md) |
| Understand or extend the implementation | [Contributor documentation](internal/README.md) |

Try the [browser playground](https://agnostic-ai.org/playground/) without installing anything, or use the [examples](examples/README.md) in a local project.
