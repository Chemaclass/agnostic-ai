# JSON Schema for agnostic-ai config and spec frontmatter

Date: 2026-05-07
Issue: https://github.com/Chemaclass/agnostic-ai/issues/30

## Goal

Give editors (VS Code, JetBrains, Neovim) inline validation and autocomplete for
`agnostic.config.yaml` and spec frontmatter files, with zero manual user setup.

## Schema files

Two files under `docs/schemas/`:

**`config.schema.json`** — generated from Go structs (`Config`, `Sources`, `Output`,
`Gitignore`) using `invopop/jsonschema`. Structs are the single source of truth;
the file is regenerated by `go run ./cmd/schemagen`.

**`spec.schema.json`** — hand-authored. Covers known frontmatter fields per kind:

| Kind   | Fields |
|--------|--------|
| All    | `name`, `description` |
| Agent  | `tools`, `model` |
| Skill  | (common only) |
| Rule   | `globs`, `alwaysApply` |
| Hook   | `event`, `matcher`, `command` |
| MCP    | `type`, `command`, `args`, `env`, `url`, `headers` |

The `x-<target>` namespace uses `additionalProperties: true` since it is
intentionally open-ended. Any field not listed above also passes through
(`additionalProperties: true` at the top level).

## Schema generator

`cmd/schemagen/main.go` — a plain `main` package (~50 lines). It uses
`invopop/jsonschema` to reflect the `Config` struct and writes the result to
`docs/schemas/config.schema.json`. Runs via `go run ./cmd/schemagen`.

No build tags. No side effects beyond writing the schema file.

## yaml-language-server hint

`renderConfig()` in `internal/cli/init.go` prepends one comment line to the
generated `agnostic.config.yaml`:

```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/Chemaclass/agnostic-ai/main/docs/schemas/config.schema.json
version: 1
...
```

The URL points at the raw file on `main`. It is hardcoded and does not vary by
`base` or `targets`.

No changes to demo spec files under `initdata/`. Spec files are matched by
editors via SchemaStore file-pattern rules, not inline comments.

## CI drift check

New job `schema` in `.github/workflows/ci.yml`:

```yaml
schema:
  name: Schema drift
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v6
    - uses: actions/setup-go@v6
      with:
        go-version: '1.23'
        cache: true
    - run: go run ./cmd/schemagen
    - run: git diff --exit-code docs/schemas/
```

Regenerates `config.schema.json` and fails if it differs from the committed
version. `spec.schema.json` is not touched by the generator.

## SchemaStore

Out of scope for this implementation. A follow-up PR to SchemaStore points at the
raw GitHub URLs once the schemas are committed and stable.
