Use Conventional Commits for all commit messages:

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation only
- `refactor:` code change without feature/fix
- `test:` tests only
- `chore:` tooling, build, deps

Subject line under 72 chars. Body explains why, not what.
